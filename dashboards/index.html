Dashboards

Dashboards are arrangements of registry components — 20 tags across 5 layouts. Each is a small JSON document with no code in it, so you can copy one, change the blocks, and share it back.

Share yours

Open any dashboard, switch to the JSON tab, copy it, and edit the blocks array — each entry is a registry component name and how many of twelve columns it takes. Add it to packages/registry/src/dashboards.ts and open a pull request. The build fails if a block names a component that does not exist, so a broken layout never ships.
