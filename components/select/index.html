Select

Single-choice listbox whose items take free-form content — dots, avatars, icons.
Forms & inputsZeusComponents
Preview
Code

Installation

Add select to your project. New to the library? Set up the design system first.

CLI
Manual
Download the CLI bundle

Save the bundle in your project folder, then run this command there. It includes the registry, tokens and example images.

bash
npx --yes --package=./zeus-ui-0.2.3.tgz zeus-ui add select

Downloads this site’s CLI, copies the source into your project and pulls in everything it needs — chevrons, cx, tokens, use-dismiss-on-outside-press. The component source is yours; imported npm packages are installed as needed.

Usage

The complete example running in the preview. Adjust the props and content for your interface.

select-demo.tsx
"use client";

import { Select, SelectItem } from "@/components/base/select/select";
import { StatusDot } from "@/components/base/badges/status-dot";

export default function SelectDemo() {
  return (
    <div className="flex flex-wrap items-start gap-6">
      <Select aria-label="Filter by price" defaultSelectedKey="all">
        <SelectItem id="all" textValue="All prices">
          All prices
        </SelectItem>
        <SelectItem id="low" textValue="Under $100">
          Under $100
        </SelectItem>
        <SelectItem id="high" textValue="Over $100">
          Over $100
        </SelectItem>
      </Select>

      <Select aria-label="Purchase status" defaultSelectedKey="completed" className="w-[142px]">
        <SelectItem id="completed" textValue="Completed">
          <StatusDot color="green" />
          Completed
        </SelectItem>
        <SelectItem id="waiting" textValue="Waiting">
          <StatusDot color="yellow" />
          Waiting
        </SelectItem>
        <SelectItem id="processing" textValue="Processing">
          <StatusDot color="indigo" />
          Processing
        </SelectItem>
      </Select>
    </div>
  );
}
