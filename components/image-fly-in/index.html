Installation

Add image fly-in to your project. New to the library? Set up the design system first.

CLI
Manual
bash
npx --yes --allow-remote=all --package=https://myzeusui.com/install/zeus-ui-0.3.3.tgz zeus-ui add image-fly-in

Run in your React project. Source, dependencies and required foundations are copied together. For your first Zeus component, import the styles once.

Usage

The complete example running in the preview. Adjust the props and content for your interface.

image-fly-in-demo.tsx
"use client";

import { ImageFlyIn } from "@/components/application/animations/image-fly-in";

// This example uses Zeus demo images. Install the component's assets
// or pass your own image URLs. Setup: https://myzeusui.com/components/image-fly-in/#installation

export default function Example() {
  return (
    <ImageFlyIn
      headline={"Everything else is noise."}
      duration={10}
      depth={2000}
      speed={1}
      pan={40}
    />
  );
}
