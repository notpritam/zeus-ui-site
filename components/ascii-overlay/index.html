ASCII Overlay

Image-aware WebGL character overlays with scroll-driven density and a static media fallback

Code
Fullscreen ↗

Installation

Add ascii overlay to your project. New to the library? Set up the design system first.

CLI
Manual
Download the CLI bundle

Save the bundle in your project folder, then run this command there. It includes the registry, tokens and example images.

bash
npx --yes --package=./zeus-ui-0.2.0.tgz zeus-ui add ascii-overlay

Downloads this site’s CLI, copies the source into your project and pulls in everything it needs — tokens. The component source is yours; imported npm packages are installed as needed.

Usage

The complete example running in the preview. Adjust the props and content for your interface.

ascii-overlay-demo.tsx
"use client";

import { AsciiOverlay } from "@/components/application/animations/ascii-overlay";

export default function Demo() {
  return (
    <div className="w-full overflow-hidden rounded-2xl">
      <AsciiOverlay
        image="/assets/annnimate/hero_profile_02.jpg"
        alt="Athlete profile with a colored ASCII overlay"
        scroll={false}
        cellSize={8}
        keyColor="auto"
      />
    </div>
  );
}
