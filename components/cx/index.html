Installation

Add cx to your project. New to the library? Set up the design system first.

CLI
Manual
bash
npx --yes --allow-remote=all --package=https://myzeusui.com/install/zeus-ui-0.3.3.tgz zeus-ui add cx

Run in your React project. Source, dependencies and required foundations are copied together. For your first Zeus component, import the styles once.

Usage

The complete example running in the preview. Adjust the props and content for your interface.

cx-demo.tsx
"use client";

import { Button } from "@/components/base/buttons/button";
import { cx } from "@/utils/cx";
import { useState } from "react";

export default function CxDemo() {
  const [compact, setCompact] = useState(false);
  const base = "rounded-2xl bg-background-secondary-default p-6 text-body-medium text-text-primary";
  const override = compact ? "p-3 text-body-2-medium" : "";
  const classes = cx(base, override);
  return (
    <div className="flex w-full max-w-xl flex-col gap-4">
      <div className="flex items-center justify-between gap-3">
        <p className="text-body-medium text-text-secondary">
          Later classes replace conflicting styles.
        </p>
        <Button
          variant="secondary"
          size="small"
          onClick={() => setCompact((value) => !value)}
          aria-pressed={compact}
        >
          {compact ? "Use spacious" : "Use compact"}
        </Button>
      </div>
      <div className={classes}>A single source of truth for spacing and typography.</div>
      <div className="flex flex-col gap-2 rounded-2xl border border-border-button-default bg-background-primary-default p-4">
        <p className="text-caption-1-medium text-text-tertiary">Result from cx()</p>
        <code className="break-words text-body-2-regular text-text-secondary">{classes}</code>
      </div>
    </div>
  );
}

Source

1 file. Source code you can read, customize and keep in your project.

utils/cx.ts
import { extendTailwindMerge } from "tailwind-merge";

/**
 * Text-style classes from styles/typography.css.
 *
 * IMPORTANT: every text-* utility we define via @theme (e.g. `text-body-medium`,
 * `text-title-1-semibold`) must be listed here. Otherwise tailwind-merge — which
 * has no view of our Tailwind theme — treats them as text-color utilities and
 * silently drops them when they appear in the same className as a real color
 * (`text-foreground-full`, `text-text-primary`, etc).
 *
 * If you add or rename a text style in typography.css, mirror the change here.
 */
const TEXT_FAMILIES = [
  "large-title",
  "display-1",
  "display-2",
  "display-3",
  "display-4",
  "title-1",
  "title-2",
  "title-3",
  "headline",
  "body",
  "body-2",
  "caption-1",
  "caption-2",
] as const;

const TEXT_WEIGHTS = ["regular", "medium", "semibold", "bold"] as const;

const TEXT_STYLE_SUFFIXES = TEXT_FAMILIES.flatMap((family) =>
  TEXT_WEIGHTS.map((weight) => `${family}-${weight}`),
);

const twMerge = extendTailwindMerge({
  extend: {
    classGroups: {
      "font-size": [{ text: TEXT_STYLE_SUFFIXES }],
    },
  },
});

/**
 * Merge Tailwind classes safely. Last-write-wins on conflicting utilities.
 */
export const cx = twMerge;

/**
 * Identity helper that gives the Tailwind IntelliSense extension a hook for
 * sorting classes inside style objects (the extension doesn't sort inside
 * plain object literals otherwise).
 */
export function sortCx<
  T extends Record<
    string,
    string | number | Record<string, string | number | Record<string, string | number>>
  >,
>(classes: T): T {
  return classes;
}
