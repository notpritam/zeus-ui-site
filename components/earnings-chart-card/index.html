Installation

Add earnings chart to your project. New to the library? Set up the design system first.

CLI
Manual
bash
npx --yes --allow-remote=all --package=https://myzeusui.com/install/zeus-ui-0.3.3.tgz zeus-ui add earnings-chart-card

Run in your React project. Source, dependencies and required foundations are copied together. For your first Zeus component, import the styles once.

Usage

The complete example running in the preview. Adjust the props and content for your interface.

earnings-chart-card-demo.tsx
"use client";

import { EarningsChartCard } from "@/components/application/charts/earnings-chart-card";

export default function EarningsChartCardDemo() {
  return (
    <div className="w-full max-w-[673px]">
      <EarningsChartCard />
    </div>
  );
}
