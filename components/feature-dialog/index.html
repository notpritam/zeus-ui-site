Installation

Add feature dialog to your project. New to the library? Set up the design system first.

CLI
Manual
bash
npx --yes --allow-remote=all --package=https://myzeusui.com/install/zeus-ui-0.2.3.tgz zeus-ui add feature-dialog

Run in your React project. Source, dependencies and required foundations are copied together. For your first Zeus component, import the styles once.

Usage

The complete example running in the preview. Adjust the props and content for your interface.

feature-dialog-demo.tsx
"use client";

import { FeatureDialog } from "@/components/application/animations/feature-dialog";
import { useState } from "react";

export default function Demo() {
  const [action, setAction] = useState("");
  return (
    <div className="w-full">
      <FeatureDialog onAction={() => setAction("Story selected")} />
      {action && (
        <p role="status" className="mt-3 text-sm">
          {action}
        </p>
      )}
    </div>
  );
}
