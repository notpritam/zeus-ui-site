Installation

Add scale slider to your project. New to the library? Set up the design system first.

CLI
Manual
bash
npx --yes --allow-remote=all --package=https://myzeusui.com/install/zeus-ui-0.2.3.tgz zeus-ui add scale-slider

Run in your React project. Source, dependencies and required foundations are copied together. For your first Zeus component, import the styles once.

Usage

The complete example running in the preview. Adjust the props and content for your interface.

scale-slider-demo.tsx
"use client";

import { ScaleSlider } from "@/components/application/animations/scale-slider";

export default function Demo() {
  return (
    <div className="w-full overflow-hidden rounded-2xl">
      <ScaleSlider minScale={0.3} autoplay={0.0016} radius={0} />
    </div>
  );
}
