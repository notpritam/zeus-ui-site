Installation

Add multi-level drawer menu to your project. New to the library? Set up the design system first.

CLI
Manual
Download the CLI bundle

Save the bundle in your project folder, then run this command there. It includes the registry, tokens and example images.

bash
npx --yes --package=./zeus-ui-0.2.1.tgz zeus-ui add multi-level-drawer-menu

Downloads this site’s CLI, copies the source into your project and pulls in everything it needs — tokens. The component source is yours; imported npm packages are installed as needed.

Usage

The complete example running in the preview. Adjust the props and content for your interface.

multi-level-drawer-menu-demo.tsx
"use client";

import { MultiLevelDrawerMenu } from "@/components/application/animations/multi-level-drawer-menu";

export default function Demo() {
  return (
    <div className="w-full overflow-hidden rounded-2xl">
      <MultiLevelDrawerMenu
        logo="Kinetic Athletics"
        exploreHref="/components/"
        sublists={{
          running: [
            { label: "Shoes", href: "/components/scale-slider/" },
            { label: "Collection", href: "/components/curtain-slider/" },
          ],
          cycling: [{ label: "Gear", href: "/components/image-fly-in/" }],
          tennis: [{ label: "Court issue", href: "/components/feature-dialog/" }],
          track: [{ label: "Membership", href: "/components/animated-pricing/" }],
        }}
      />
    </div>
  );
}
