Installation

Add multi-level drawer menu to your project. New to the library? Set up the design system first.

CLI
Manual
bash
npx --yes --allow-remote=all --package=https://myzeusui.com/install/zeus-ui-0.3.1.tgz zeus-ui add multi-level-drawer-menu

Run in your React project. Source, dependencies and required foundations are copied together. For your first Zeus component, import the styles once.

Usage

The complete example running in the preview. Adjust the props and content for your interface.

multi-level-drawer-menu-demo.tsx
"use client";

import { MultiLevelDrawerMenu } from "@/components/application/animations/multi-level-drawer-menu";

// This example uses Zeus demo images. Install the component's assets
// or pass your own image URLs. Setup: https://myzeusui.com/components/multi-level-drawer-menu/#installation

export default function Example() {
  return (
    <MultiLevelDrawerMenu
      duration={0.9}
      stagger={0.06}
      panelBg={"#171717"}
      heroHeading={"Move with purpose."}
    />
  );
}
