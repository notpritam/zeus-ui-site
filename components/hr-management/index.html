HR Management

Hiring, engagement and employee management with editable records
Complete screensZeusTemplates
Preview
Code
Open preview

1440 × 900 viewport · 50% scale. Open the preview to use it at full size.

Installation

Add hr management to your project. New to the library? Set up the design system first.

CLI
Manual
bash
npx --yes --allow-remote=all --package=https://myzeusui.com/install/zeus-ui-0.3.1.tgz zeus-ui add hr-management

Run in your React project. Source, dependencies and required foundations are copied together. For your first Zeus component, import the styles once.

Usage

The complete example running in the preview. Adjust the props and content for your interface.

hr-management-demo.tsx
"use client";

import { HRManagement } from "@/components/application/templates/hr-management";

export default function Demo() { return <div className="h-[900px] w-[1440px] max-w-none"><HRManagement contained /></div>; }
