Finance Dashboard

Personal finance workspace with cash flow, investments, spending and transaction records
Preview
Code
Open preview

1440 × 900 viewport · 50% scale. Open the preview to use it at full size.

Installation

Add finance dashboard to your project. New to the library? Set up the design system first.

CLI
Manual
Download the CLI bundle

Save the bundle in your project folder, then run this command there. It includes the registry, tokens and example images.

bash
npx --yes --package=./zeus-ui-0.1.0.tgz zeus-ui add finance-dashboard

Downloads this site’s CLI, copies the source into your project and pulls in everything it needs — app-shell, avatar, badge, breadcrumb, button, chart-card, checkbox, chevrons, chip, close-button, cx, date-picker, dropdown, file-upload, heatmap-chart-card, icon-button, input, kbd, notification-center, pagination, radial-chart-card, sankey-chart-card, scatter-chart-card, segmented-control, select, settings-modal, sidebar, stat-cards, switch, table, tabs, theme-toggle, tokens, tooltip, use-count-up, use-dismiss-on-outside-press. The component source is yours; imported npm packages are installed as needed.

Usage

The complete example running in the preview. Adjust the props and content for your interface.

finance-dashboard-demo.tsx
"use client";

import { FinanceDashboard } from "@/components/application/templates/finance-dashboard";

export default function Demo() { return <div className="h-[900px] w-[1440px] max-w-none"><FinanceDashboard contained /></div>; }
