Getting started

Add a component with one command, import it, and start building. React and Tailwind CSS v4 are required for the Zeus foundation.

Installation

Start with a React application using Tailwind CSS v4. The CLI copies component source and resolves its registry dependencies.

bash
npx --yes --allow-remote=all --package=https://myzeusui.com/install/zeus-ui-0.3.3.tgz zeus-ui add button

Run this in your project. It copies the button, its dependencies and token styles. No separate download or initialization is needed.

Import the styles once

For components using the Zeus foundation, add this to your global stylesheet. The paths below assume your stylesheet is in app/globals.css. With a src folder, use src/app/globals.css.

app/globals.css
@import "../styles/zeus/index.css";

/* Include source-owned components in Tailwind scanning. */
@source "../components";
tsx
import { Button } from "@/components/base/buttons/button";

export function Example() {
  return <Button>Continue</Button>;
}

Choose another component and copy its install command. The CLI detects your package manager and source folder. Use zeus.json if your import alias differs from @/.

React SDK

Prefer package imports? Install the versioned React SDK directly. These packages are served by Zeus while npm publication is being prepared.

bash
npm install --allow-remote=all https://myzeusui.com/install/sdk/zeus-ui-0.3.3.tgz https://myzeusui.com/install/sdk/zeus-tokens-0.3.3.tgz
tsx
import { Button } from "@zeus/ui/base";

export function Example() {
  return <Button>Continue</Button>;
}
css
@import "@zeus/tokens";
/* Adjust this path relative to your stylesheet. */
@source "../node_modules/@zeus/ui/dist";

Templates use example data and documented callbacks for your backend. The source installer also copies example images; package consumers provide their own assets or install the matching template with the CLI.

Agents can read the component manifest for all examples, dependencies and source URLs, or start with llms.txt.

Zeus Icons

Use named React components from the Zeus Icons package. Individual imports keep your bundle small; size and color stay under your control.

bash
npm install https://github.com/notpritam/zeus-icons/releases/download/v0.1.0/zeus-icons-0.1.0.tgz
tsx
import { Home01StrokeRoundedIcon } from "zeus-icons/stroke-rounded/Home01StrokeRoundedIcon";

<Home01StrokeRoundedIcon size={24} color="currentColor" title="Home" />

Design tokens

Components built for the Zeus foundation use semantic colors and composite typography. The same class names work in light and dark themes.

PurposeUtility
Page surfacebg-background-full
Card surfacebg-background-secondary-default
Primary texttext-text-primary
Secondary texttext-text-secondary
Dividersborder-separator-border
Page headingtext-title-1-medium
Body copytext-body-regular
components/save-action.tsx
import { Button } from "@/components/base/buttons/button";

export function SaveAction() {
  return <Button variant="primary">Save changes</Button>;
}

Use cx() from your installed utility when combining classes. It understands the composite typography utilities.

Dark mode

The dark class on the root HTML element switches the semantic tokens. Install the theme toggle to give readers a persistent light/dark control.

bash
npx --yes --allow-remote=all --package=https://myzeusui.com/install/zeus-ui-0.3.3.tgz zeus-ui add theme-toggle

Customize the Zeus accent by overriding its accent ramp after the foundation import. This updates controls that consume those tokens; data colors and independent component styling keep their own meaning.

globals.css
@import "@zeus/tokens";

:root {
  --color-accent-500: #7c3aed;
  --color-accent-600: #6d28d9;
}
/* Override the full accent ramp for a complete theme. */

Apply the saved preference before the first paint to avoid a theme flash:

Before interactive scripts
<script>
  try {
    const dark = localStorage.getItem("zeus:theme") === "dark";
    document.documentElement.classList.toggle("dark", dark);
  } catch {}
</script>

Install with your agent

The Zeus MCP server lets your coding agent browse the registry, read component source and find the tokens it needs.

bash
claude mcp add zeus -- npx --yes --allow-remote=all --package=https://myzeusui.com/install/zeus-mcp-0.3.3.tgz zeus-mcp

For clients that use a JSON configuration:

MCP configuration
{
  "mcpServers": {
    "zeus": {
      "command": "npx",
      "args": [
        "--yes",
        "--allow-remote=all",
        "--package=https://myzeusui.com/install/zeus-mcp-0.3.3.tgz",
        "zeus-mcp"
      ]
    }
  }
}

Try asking your agent: “Find an agent limits component, show its usage, and add it to my project.”

A library with room for different systems

Start with what you need: a button, navigation, a chart or an icon resource. A component family brings those choices together, even when their visual styles differ.

Browse byWhat it tells you
FamilyPurpose: buttons, forms, navigation, icons, media and more.
Resource typeWhat you install: a component, animation, template, token set or icon resource.
Design systemThe shared visual conventions and foundations a component follows.
CollectionAn editorial selection: featured work, trending picks or everyday essentials.

Zeus is currently the one registered design system. The animation collection includes independent visual styles; these are listed separately and still declare the setup they require. This filter organizes the library—it does not retheme a preview.

A theme changes a system’s colors, fonts or token values. Another design system may also change component structure, sizing, behavior and icon conventions. Its foundation is registered separately. Combining different global foundations requires deliberate integration; selecting a system does not convert another system’s components.

Icon resources are separate from icon-library dependencies. Zeus currently includes its custom chevrons, while many components depend on the external Remix Icon React package. Zeus Icons is available as its own package and browser, without requiring a new design system.
