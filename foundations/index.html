Getting started

A consistent design system, with the source in your project. Set up the tokens once, then add the components you need.

Installation

Start with a React application using Tailwind CSS v4. The CLI copies component source and resolves its registry dependencies.

1. Initialize your project

Download the CLI bundle

Save the bundle in your project folder, then run this command there. It includes the registry, tokens and example images.

bash
npx --yes --package=./zeus-ui-0.2.1.tgz zeus-ui init

This writes zeus.json with your component paths and import alias, and installs the local token styles.

2. Add the design tokens

Initialization copies the token styles into your project. Import them from your global stylesheet, adjusting the relative path to match its location.

app/globals.css
@import "../styles/zeus/index.css";

/* Include source-owned components in Tailwind scanning. */
@source "../components";

3. Install your first components

Download the CLI bundle

Save the bundle in your project folder, then run this command there. It includes the registry, tokens and example images.

bash
npx --yes --package=./zeus-ui-0.2.1.tgz zeus-ui add button input select

Open a component page for its live preview, usage example and complete source. Each page also includes manual installation instructions.

React SDK

Import the reusable React packages directly, or use the CLI above to own the source. These versioned packages are served by Zeus; no npm registry release is required.

bash
npm install https://myzeusui.com/install/sdk/zeus-ui-0.2.1.tgz https://myzeusui.com/install/sdk/zeus-tokens-0.2.1.tgz
tsx
import { Button } from "@zeus/ui/base";
import { AgentLimitsCard } from "@zeus/ui/application";

export function Example() {
  return <><Button>Continue</Button><AgentLimitsCard context={{ max: 1_000_000, segments: [{ label: "Messages", tokens: 520_000 }] }} /></>;
}
css
@import "@zeus/tokens";
/* Adjust this path relative to your stylesheet. */
@source "../node_modules/@zeus/ui/dist";

Templates use example data and documented callbacks for your backend. The source installer also copies example images; package consumers provide their own assets or install the matching template with the CLI.

Agents can read the component manifest for all examples, dependencies and source URLs, or start with llms.txt.

Design tokens

Components use semantic colors and composite typography. The same class names work in light and dark themes.

components/save-action.tsx
import { Button } from "@/components/base/buttons/button";

export function SaveAction() {
  return <Button variant="primary">Save changes</Button>;
}

Use cx() from your installed utility when combining classes. It understands the composite typography utilities.

Dark mode

The dark class on the root HTML element switches the semantic tokens. Install the theme toggle to give readers a persistent light/dark control.

Download the CLI bundle

Save the bundle in your project folder, then run this command there. It includes the registry, tokens and example images.

bash
npx --yes --package=./zeus-ui-0.2.1.tgz zeus-ui add theme-toggle

Apply the saved preference before the first paint to avoid a theme flash:

Before interactive scripts
<script>
  try {
    const dark = localStorage.getItem("zeus:theme") === "dark";
    document.documentElement.classList.toggle("dark", dark);
  } catch {}
</script>

Install with your agent

The Zeus MCP server lets your coding agent browse the registry, read component source and find the tokens it needs.

Download the MCP bundle

Save the bundle locally and replace the example path below with its absolute path.

bash
claude mcp add zeus -- npx --yes --package=/absolute/path/zeus-mcp-0.2.1.tgz zeus-mcp

For clients that use a JSON configuration:

MCP configuration
{
  "mcpServers": {
    "zeus": {
      "command": "npx",
      "args": [
        "--yes",
        "--package=/absolute/path/zeus-mcp-0.2.1.tgz",
        "zeus-mcp"
      ]
    }
  }
}

Try asking your agent: “Find an agent limits component, show its usage, and add it to my project.”
