Build with your agent

Give your coding agent the same library you see here. Search components, read usage examples and install the right source with the Zeus MCP server.

Connect the MCP server
Download the MCP bundle

Save the bundle locally and replace the example path below with its absolute path.

bash
claude mcp add zeus -- npx --yes --package=/absolute/path/zeus-mcp-0.2.1.tgz zeus-mcp

For clients that use a JSON configuration:

MCP configuration
{
  "mcpServers": {
    "zeus": {
      "command": "npx",
      "args": [
        "--yes",
        "--package=/absolute/path/zeus-mcp-0.2.1.tgz",
        "zeus-mcp"
      ]
    }
  }
}
Download the CLI bundle

Save the bundle in your project folder, then run this command there. It includes the registry, tokens and example images.

bash
npx --yes --package=./zeus-ui-0.2.1.tgz zeus-ui add agent-limits-card

A few things to know

How do I add a component?

Use the installation command on any component page to set up the design tokens and add components. The CLI copies its source files into your project and resolves the dependencies. Every component page also includes a manual installation guide.

Can I change the source?

Yes. The components live in your project and are MIT licensed. Change their styles, behavior and content to suit what you are building.

Does the library support dark mode?

Yes. Components use semantic design tokens that change with the dark class on your HTML element. Use the theme toggle in the navigation to explore both themes.

Can my coding agent use the library?

The Zeus MCP server gives your agent access to component search, usage examples, source files and design tokens. The setup guide includes configuration for your MCP client.
