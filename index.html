Questions

What is Zeus?
A library of the best interface components we can find, rebuilt as React you own. Every one runs live here, so you see exactly what you get before your agent installs it.
Is it free?
Yes. Every component, its source, the Studio and the MCP server. Nothing is behind a plan.
How does my agent use it?
Connect the Zeus MCP server and your agent can search, read and install any component by name. Or paste the prompt the Studio writes for you. How to connect it.
What is the Studio?
A full-screen editor around a complete app template. The template runs live at desktop, tablet and phone size while you change its font, colour, corners and light or dark. It turns the result into one prompt and one install command.
Can I use them in client work?
Yes, in anything you make, personal or commercial, with no credit needed.
Will it match what I see?
The code you copy is the code running on the page, with the same props and dependencies pinned to the versions it was built with.
