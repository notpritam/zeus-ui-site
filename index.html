Before you build.

A few things you might want to know.

Read the docs
What can I build with Zeus?

Websites, dashboards, AI products, data views and the details in between. Start from a complete template or bring individual React components into your existing project.

How does my agent use the library?

Connect Zeus through MCP to give your coding agent component search, examples and source. Choose an interface above and copy its agent brief for a concrete starting point. You can also use the React SDK or install source with the CLI.

Can I change the design?

Yes. Adapt the content, styling and supported settings, or install the source and change the component itself. Each component keeps its own design dependencies, so using one style does not force it across your whole project.

Are the templates connected to live data?

The templates use example data so you can explore them immediately. Connect your own data, authentication and AI service in your application. The examples and component documentation show where to start.

How are the collections chosen?

Featured and trending picks are editorial selections of useful interface patterns and expressive interactions. They are curated by Zeus, rather than ranked by download counts.
