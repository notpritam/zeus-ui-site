A few useful answers.

What can I build with Zeus?

Websites, dashboards, AI products, data views and the details in between. Explore individual React components or start from a complete interface.

How does my agent use the library?

Connect Zeus through MCP to give your coding agent component search, examples and source. You can also use the React SDK or copy components into your project with the CLI.

What makes a component a trending pick?

It’s an editorial selection of expressive interaction patterns and useful interface ideas from the library. The collection is curated by Zeus, rather than ranked by download counts.

Can I make the components my own?

Yes. Source installation puts the component in your project, where you can change its content, styling and behavior. Component and dependency notices are included with the source.
