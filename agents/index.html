For agents

Zeus is built to be read by coding agents. Connect the MCP server, use the CLI, or add items from the shadcn registry. All three install the same source.

MCP server

Add Zeus to your agent's MCP configuration. It can then list, search, read and install components, and fetch the design tokens.

{
  "mcpServers": {
    "zeus": {
      "command": "npx",
      "args": ["--yes", "--allow-remote=all", "--package=https://myzeusui.com/install/zeus-mcp-0.4.0.tgz", "zeus-mcp"]
    }
  }
}

Tools: list_components, search_components, get_component, install_components, get_tokens.

CLI

Install any component by name. Dependencies come pinned to the ranges the source was built with.

npx --yes --allow-remote=all --package=https://myzeusui.com/install/zeus-ui-0.4.0.tgz zeus-ui add magnetic-button segmented-control

shadcn registry

Every component is also a shadcn registry item.

npx shadcn@latest add https://myzeusui.com/r/magnetic-button.json

zeus.json

The Studio exports a recipe: the template, the style you picked, the components to install and the tokens to set. Attach it to your prompt and the agent has nothing to guess.

zeus.json
{
  "schemaVersion": 1,
  "sdkVersion": "0.4.0",
  "template": { "id": "home-dashboard", "name": "Home Dashboard", "kind": "Dashboard" },
  "family": "apollo",
  "slots": {
    "colour": { "choice": "laurel", "label": "Laurel", "active": true, "locked": true },
    "mode": { "choice": "dark", "label": "Dark", "active": true, "locked": false }
  },
  "elements": ["tokens", "home-dashboard"],
  "tokens": { "--color-accent-500": "#0f9d7a", "--color-accent-600": "#087f64" }
}
