Liquid Glass Recorder

A voice recorder made of real refracting glass. It bends what is behind it, glows through the spectrum while you speak, and settles like liquid when you let go.

First releasePressWebGL
  • Refraction with dispersion at the edges
  • Spring physics: it stretches, wobbles and snaps back
  • 65 values, every one a prop
  • A plain fallback where WebGL is off

Press the button and speak. Without microphone access it plays a demo take.

Use it

One component. Pass any of its 65 values through params; anything you leave out keeps the tuned default.

import { LiquidGlassRecorder } from "@/components/liquid-glass-recorder";

export function VoiceNote() {
  return (
    <div style={{ height: 480 }}>
      <LiquidGlassRecorder
        params={{ thickness: 12, frost: 0.3, glowColors: ["#ffb340", "#ff3d84", "#4f7dff"] }}
        onStop={({ blob, duration }) => save(blob, duration)}
      />
    </div>
  );
}

It ships in Zeus with its source, a live playground and an install command, like every other component.
